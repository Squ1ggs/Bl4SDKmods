# BL4 Player Movement

Sliders for on-foot speed, jump, gravity, and other movement values.

## Install

1. Copy `bl4_player_movement.sdkmod` into your game's `sdk_mods` folder.
2. Restart, open the console, run `mods`, and enable the mod.

## In-game

Requires BLImGui. In the mods menu go to **Keybinds** and bind **Show/hide BLImGui menu — Player Movement**.

Console help: `player_move_help`
