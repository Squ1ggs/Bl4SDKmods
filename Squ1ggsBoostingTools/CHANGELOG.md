## 3.10.35 / EXE 1.3.35
- **MAX ALL** — new **Mayhem level skip** option (+ Mayhem Rank, default 20): skips the first normal clear for the Boost target or the whole lobby. Off by default; same unlock as Progress → Takedown mayhem.

- **Show FPS** — new toggle next to Hide HUD (same places): turns on the game's own FPS counter.
- **Photo presets** (Display tab): **Clean screen** (HUD + FPS counter off), **Freecam photo** (clean + freecam), **Wide photo** (clean + wider FOV). Turning one off puts back exactly what it changed. Clean screen is also a bindable key.

- **Tabs tidied** so each tool lives where you'd look for it: Takedown mayhem and Economy (cash / eridium / levels / SDU / bag sizes) → **Progress**; Black market → **World**; Party host (roster / kick) → **Auto Lobby**; all party teleports → **Mobility → Party teleports**; the full Freecam set (controls, placing) → **Freecam** tab. - **No death penalty** — new Boost-target toggle (Home → Most used, Mobility, Toggles board, in-game panel): no repeat-down penalty and no death cost; stays on through respawns, OFF puts the normal values back.
