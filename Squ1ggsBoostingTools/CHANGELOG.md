# Changelog

## 3.9.2 / EXE 1.2.2
- **Auto Lobby:** optional guest-only Challenges/UVHM mode skips the host, waits when empty, and picks up newly joined guests using normal roster polling.
- **GZO drip:** red countdown before the backpack spill; stalled spills disable drip instead of mailing another pile on top.
- **Challenge bulk:** ULM-safe pacing, accurate progress, and already-complete challenges are skipped on re-runs.
- **Reward safety:** Complete ALL only sends rewards. Large pending queues are blocked in multiplayer; console/cross-play users should open in solo, sell junk, then rejoin.
- **Grassroots Campaigner:** focused retry button for the known 96/98 case after one side mission creates its save state.
- **Save / Live icons:** fixed broken backpack SVGs (invalid control char in the icon files).
- **MAX ALL:** progress bar arms when challenges are queued (not only UVHM).
- **God mode:** sticky toggle follows live ULM fields + response sync (no more on/off thrash).
- **Send packs / rewards:** floating progress shows immediately on first send while mail queues.

## 3.9.1 / EXE 1.2.1

Version reset: EXE jumps **1.1.x → 1.2.1**, mod **3.8.x → 3.9.1** (no more triple-digit patches). Future EXE patches stay **1.2.2 … 1.2.9**, then **1.3.1**.

### Highlights
- **Auto Lobby** — timed host boost loops (MAX ALL, challenges, UVHM, cosmetics, GZO drip pile for the lobby). Cleaner labels; hold / rest-gap fixes so cycles don’t thrash.
- **Challenge + UVHM progress** — floating bar you can drag, real milestone steps on huge bulk runs, green ✓ when done, auto-hides when idle.
- **Loot shapes + shinies** — house / boat / vault dumps; co-op friends can grab; Drop All Shinies; pull world loot to your feet.
- **Serials & My packs** — paste `@U`, mail the lobby, open Reward Center packages at a sane pace.
- **Map unlock** — clear fog / widen FoD the MSBT way (no fiddly radius field).
- **No main menu** — stop guests yanking the host to title while you boost.
- **Save Pack / Live Pack** — read `@U` from your autosave or a live Boost-target snap, quick relevel, Send to party. Cyan vs magenta backpack icons.

### Also
- Safer serial open-rewards pacing; shape line lengths capped; vacuum = feet pull (never mail).
- EXE UI polish: tighter pack tabs, progress drag that sticks where you drop it.
