## What's new

- **Progress bar** — shows **Complete ✓** when challenges or UVHM finish, then closes (no stuck box after MAX ALL)
- **MAX ALL** — UVHM starts after non-UVHM challenges when both are checked
- **All players challenges** — one seat at a time (guests first); bar tracks everyone
- **UVHM bar** — fills through settle; Stop cancels and hides cleanly
- **Defaults** — cosmetics + hover on; non-UVHM challenges off; Rewrite item level on

## Install / update

1. Fully quit Borderlands 4 (and any old SQBT EXE).
2. Run the new portable `Squ1ggsBoostingTools.exe`.
3. Let it sync the mod, then start Borderlands and load a character.
