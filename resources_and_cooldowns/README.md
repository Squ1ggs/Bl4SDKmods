# Resources & Cooldowns

Sustain tuning — repair kit charges and cooldown, overshield, Second Wind recovery, lifesteal, and ammo regen. Pairs with **Damage & More** but works fine on its own.

**Mods menu** and **console** (`brc_help`, `brc_apply`, `brc_reset`) cover the basics. For a BLImGui panel, install **[BLImGui](https://github.com/juso40/blimgui)**, enable it, then bind **Open Resources & Cooldowns tab** (default **Ctrl+Shift+F12**). Apply shortcut: **Ctrl+Shift+F10**.

## Install

Requires [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `resources_and_cooldowns.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **Resources & Cooldowns**.
3. Optional: BLImGui + keybind above.

**Sticky re-apply** helps if values drift during long sessions. Client-side local player tuning. MIT license.
