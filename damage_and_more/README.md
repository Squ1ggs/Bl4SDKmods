# Damage & More

Combat sliders — outgoing and incoming damage, elemental scaling, repair kits, shields, Second Wind, melee, and a handful of deeper damage-state tweaks.

**Mods menu** and **console** (`bdam_help`, `bdam_apply`, `bdam_reset`) work on their own. For a BLImGui panel with numeric inputs under each slider, install **[BLImGui](https://github.com/juso40/blimgui)**, enable it, then bind **Open Damage & More tab** under **Mods → Keybinds** (default **Ctrl+Shift+F11**). Apply shortcut: **Ctrl+Shift+F10**.

## Install

Requires [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `damage_and_more.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **Damage & More**.
3. Optional: BLImGui + keybind above.

Turn on **Sticky re-apply** in the mods menu if BL4 keeps resetting your numbers mid-fight. Re-run apply after respawn or travel if something drifts.

Works standalone. **Squ1ggs Boosting Tools** can share the same settings if you run both. Client-side — your pawn only. MIT license.
