# Challenge Ticker

UVHM ranks 1-7 and challenge completion. Host / listen only - **back up your save**.

Mods menu + console (`bl4cu_*`). Optional panel (Ctrl+F7) only if you already have a BL4-capable BLImGui.

## Install

Needs [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `challenge_ticker.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **Challenge Ticker**.

Doesn't finish story missions. Some achievements still need real mission progress; the mod says when. Standalone - nothing else from my repo required. MIT.
