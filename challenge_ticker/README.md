# Challenge Ticker

Finish challenges and run the UVHM rank 1–7 sequence without clicking through every menu yourself.

The main UI is a **BLImGui** tab — install **[BLImGui](https://github.com/juso40/blimgui)** separately, enable it, then bind **Open Challenge Ticker** under **Mods → Keybinds** (default **Ctrl+F7**). You can also use **Mods → Challenge Ticker** and console commands (`bl4cu_open`, `bl4cu_status`, `bl4cu_players` — run `mods` and check the mod's command list).

## Install

Requires [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `challenge_ticker.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **Challenge Ticker**.
3. Install **BLImGui** if you want the panel (recommended).

## Before you run anything

**Back up your save.** Challenge and UVHM changes stick. Use this on **host / listen**, not as a random join client.

This does not finish story missions — it only flips challenge flags. Some achievements still need real mission progress first; the mod will tell you when that's the case.
