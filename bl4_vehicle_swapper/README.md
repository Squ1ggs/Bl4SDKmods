# BL4 Vehicle Swapper 0.1.2

Change the look of a car in Borderlands 4. Driving and handling stay the car you are actually using. The wheels stay visual. Roof pods and launchers do not fire.

No cars are included. A car shows up only after you install a car pack.

Download: [bl4_vehicle_swapper.sdkmod](https://github.com/Squ1ggs/Bl4SDKmods/releases/download/bl4-vehicle-swapper-v0.1.2/bl4_vehicle_swapper.sdkmod)

The same file is in this folder as `bl4_vehicle_swapper.sdkmod`.

Use this mod, or use Squ1ggs Boosting Tools. You do not need both. In the desktop app, car looks are on the Vehicle page under Car appearance.

## Install

1. Close Borderlands 4.
2. Put `bl4_vehicle_swapper.sdkmod` in the game's `sdk_mods` folder. Keep that filename.
3. Install a car pack. In the desktop app, use Add pack. Without the app, extract the ZIP into the Borderlands 4 folder that contains `OakGame` and `sdk_mods`.
4. Start the game and enable **BL4 Vehicle Swapper**.
5. Refresh the car list.

You need the BL4 Python SDK. BLImGui is optional and is only the F11 picker. The mod menu works without it.

Summon car, Use on my vehicle, Preview car, and Restore vehicle are in the mod options.

Car packs: [original character and vehicle packs](https://github.com/Squ1ggs/Bl4SDKmods/releases/tag/bl4-original-model-packs-v0.1)
