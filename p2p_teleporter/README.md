# P2P Teleporter

See who's in the session and move people around — pull a player to you, jump to them, or bring everyone in.

**Mods menu** has roster buttons and a player picker. For the BLImGui tab, install **[BLImGui](https://github.com/juso40/blimgui)**, enable it, then bind **Open P2P Teleporter tab** under **Mods → Keybinds**. Console: `bcst_roster`, `bcst_to_me`, `bcst_me_to`, `bcst_help`.

## Install

Requires [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `p2p_teleporter.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **P2P Teleporter**.
3. Optional: BLImGui + keybind above.

Host authority usually matters for moving other players. MIT license.
