# World Travel

Save where you are and jump back later — five quick slots, named bookmarks, plus a travel-station catalog.

**Mods menu** has the slot buttons. For the BLImGui browser, install **[BLImGui](https://github.com/juso40/blimgui)**, enable it, then bind **Open World Travel tab** under **Mods → Keybinds**. Console: `bwt_save`, `bwt_go`, `bwt_list`, `bwt_help`.

## Install

Requires [Oak2 Mod Manager v0.3+](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

1. Drop `world_travel.sdkmod` into `sdk_mods`.
2. Restart, run `mods`, enable **World Travel**.
3. Optional: BLImGui + keybind above.

Bookmarks persist in your mod settings between sessions. MIT license.
