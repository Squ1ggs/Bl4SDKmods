What to do first

  1. Set your Borderlands 4 install folder — open Setup and press Set install folder. Pick the folder that contains Borderlands4.exe / OakGame (Steam on another drive is fine, e.g. D:\SteamLibrary\steamapps\common\Borderlands 4).
  2. Install SDK once if prompted — then fully restart Borderlands 4.
  3. Load a character — get in-world. The main menu will not unlock the buttons.
  4. Wait for Online — this window should say Connected. Then use the tabs.

Stuck Offline? Set the correct install folder → fully restart the game → load a character → Refresh status. Other tools: GitHub · save editor scooterstoolbox.com
